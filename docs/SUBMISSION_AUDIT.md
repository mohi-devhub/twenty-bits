## 2. Key numbers vs baselines and oracle

The slice is the same 28 frozen noiseless animal cases per size at N=32 and N=128. The audit joined the archived references and model runs by game ID. EIG divides total bits by total counted questions within each size, then averages the two size values. The model EIG values below are copied from the write-up data at stored precision. Questions per win give the exact numerator and denominator from the game rows. Lower values can reflect lucky early guesses and the different cases each policy wins. [Model game archives](../results/main_A11/), [A23 archive](../results/main_A23/), [B41 archive](../results/main_B41/), [write-up data](../results/writeup/numbers.json), [frozen reference archive](../results/baselines/frozen/).

The greedy predicate reference used exactly 5 questions on each N=32 game and 7 on each N=128 game, matching `log2(N)` on this noiseless slice. It scores splits over at most two attributes using the exact posterior. In noisy games it can repeat a question under its confirmation rule. Its restricted search and stopping rule do not establish an optimal noisy win rate. The trained policies finished 32, 31 and 37 wins behind this reference on the 56-game slice. [Frozen reference rows](../results/baselines/frozen/), [baseline code](../twenty_bits/baselines.py).

Across all 280 primary cases, raw wins 141, A11 wins 104, A23 wins 138, and B41 wins 127. On the 140 noisy primary cases those counts are 52, 31, 29 and 36. Treat the noiseless animal EIG gain, the full-bank win comparison, and the separate visible-budget intervention as distinct results. ## 3. Claims to drop or soften

- **Blog opening and X post 1.** Qualify “question quality improved in every seed” immediately with “on noiseless animal games.” Synthetic transfer is mixed, and the primary win counts across the full bank are lower than raw for all three trained endpoints. [Primary and transfer results](../RESULTS.md).
- **Blog budget section and X post 5.** Drop “stalling depended on missing explicit budget state,” the one-line causal headline, and any attribution to the final instruction alone. The observed prompt variant adds both a running counter and an explicit final-guess instruction. A23's no-guess endings went from 136 to 0 and wins from 138/280 to 186/280 under that variant. The experiment cannot isolate which prompt element contributed. [Intervention protocol](../VISIBLE_BUDGET_PROTOCOL.md), [saved comparison](../results/visible_budget/summary.json).
- **Blog noise section and X post 6.** Keep the primary counts and the qualified statement about noisy training. B41's interval versus mean A includes zero, with only one B seed. Under visible budget A23 wins 74/140 noisy games and raw wins 57/140. A23 used truthful training, so this is evidence about the prompt intervention. [Noise comparison](../results/main_B41/all_seeds.json), [follow-up](../results/visible_budget/summary.json).
- **Blog limits and X post 8.** Specify that held-out *profiles* and frozen games did not enter the main gradients. The same underlying animal types can appear in both pools. Use exact recorded spend of $23.681223 and holds of $2.083181 where dollar figures are reported. The thread rounds both, and the blog's approximate cost heading can give way to its exact figures. [World split](../data/WORLDS.md), [ledger](../ledger.json), [saved spend totals](../results/writeup/numbers.json).
- **Blog checkpoint wording and X post 3.** Say A11's checkpoint was unavailable for the later hosted reruns. Use the measured gap to the greedy reference for the search claim and identify Qwen3-8B as the provider model before Twenty Bits training. Its own model card records pretraining and post-training. [A11 availability record](../results/A11_suffix_diagnostic/not_run.json), [frozen reference rows](../results/baselines/frozen/), [Qwen model card](https://huggingface.co/Qwen/Qwen3-8B).

The blog's other numerical claims about the primary slice, failure counts, update 23, and the sampler–trainer diagnostic agree with the saved artifacts at the precision printed in the post. The submission should use saved values and counts. The illustrated A11/A23 contrast is a behavior-filtered example.
