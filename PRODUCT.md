# Twenty Bits replay

The replay helps GitHub readers and people on X understand how two question-asking policies narrow the same candidate set. It is a static HTML artifact in this research-style side project, with local GIF and MP4 exports. All visible questions, answers, probabilities, and results come from saved game logs.

It must support two players on the same hidden target, changing question/answer text, a candidate grid, noisy posterior weights, and playback controls. Baselines supply the Phase 1 examples. Base and trained model logs will use the same format later. No result is presented as trained-model behavior in this phase.

The user requested the page and media exports as part of offline Phase 1. Nothing is published or sent to an external service. The primary platform is desktop web, with readable stacked panels on narrow screens. Plain HTML, CSS, and JavaScript are sufficient for this artifact.
